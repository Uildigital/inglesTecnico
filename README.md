O **SN Tech English** é uma plataforma de estudo inteligente desenvolvida para acelerar o aprendizado de inglês técnico focado no ecossistema **ServiceNow**. Este projeto foi criado como parte da jornada de certificação e capacitação tecnológica.

## 🌟 Diferenciais do Projeto

- **Mentor de IA Integrado:** Utiliza o modelo GPT da OpenAI para analisar as respostas do usuário em tempo real, fornecendo feedbacks técnicos precisos e correções linguísticas.
*   **Banco de Dados Dinâmico:** Integrado com Supabase para gestão escalável de termos (Básico, Intermediário e Avançado).
- **Design Premium:** Interface moderna inspirada no ServiceNow, utilizando Glassmorphism e animações fluidas com Framer Motion.
- **Foco em Certificação:** Base de dados rica em termos reais das provas CSA e CAD.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React.js, Lucide Icons, Framer Motion.
- **Estilização:** CSS3 Moderno (Custom Properties, Flexbox, Grid).
- **Backend as a Service:** Supabase (PostgreSQL).
- **Inteligência Artificial:** OpenAI API (GPT-3.5 Turbo).

## 🚀 Como Executar o Projeto

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/seu-usuario/sn-tech-english.git
    cd sn-tech-english
    ```

2.  **Instale as dependências:**
    ```bash
    npm install
    ```

3.  **Configure as variáveis de ambiente:**
    - Renomeie o arquivo `.env.example` para `.env`.
    - Preencha com suas chaves do Supabase e OpenAI.

4.  **Prepare o Banco de Dados:**
    - Execute o script contido em `supabase_setup.sql` no SQL Editor do seu projeto Supabase.

5.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```
